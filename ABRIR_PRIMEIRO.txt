CENTRAL DE MÍDIA — NOVA VERSÃO R2
================================

Esta versão NÃO usa Supabase Storage para os vídeos.

Vídeos: Cloudflare R2 multipart
Login/metadata/realtime: Supabase
API segura: Cloudflare Worker

ORDEM:
1) Execute supabase-setup.sql no Supabase.
2) Preencha SUPABASE_URL e SUPABASE_KEY em config.js.
3) Rode CRIAR_4_USUARIOS.ps1.
4) Entre na pasta worker e siga o README para criar o bucket R2 e publicar o Worker.
5) Cole a URL do Worker em WORKER_URL no config.js.
6) Publique o site.

IMPORTANTE:
- NÃO coloque sb_secret_... dentro de config.js.
- NÃO torne o bucket R2 público.
- O site foi configurado para até 20 GiB por vídeo.
- Um vídeo de 4 GB é enviado por multipart normalmente.
